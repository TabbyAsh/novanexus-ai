# Nova Lens — install (2 minutes, one time)

1. Open Chrome → go to `chrome://extensions`
2. Toggle **Developer mode** (top right)
3. Click **Load unpacked** → select this folder (`nova-enterprises/apps/extension`)
4. Open ANY eBay listing (an `/itm/` page).

The card appears on its own — top right. It read the listing, pulled real
sold comps from your own eBay view, and gave you the verdict: sold range,
fees, net profit, max buy, time to sell, plus a one-click offer message.

No typing. No pasting. That's the point.
