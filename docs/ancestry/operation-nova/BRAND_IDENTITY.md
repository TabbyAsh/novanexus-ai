## 🎨 Visual Identity System

### Logo System

#### Primary Logomark
```
    ★
   ╱│╲
  ╱ │ ╲
 ╱  │  ╲
▀▀▀▀▀▀▀▀▀
 N O V A
```

**Concept**: The star represents aspiration and intelligence. The upward triangular form suggests growth, innovation, and reaching new heights. The base grounds it in stability and trust.

#### Logo Variations

**Full Logo**: `★ NOVA ENTERPRISES`
- Use for: Official documents, presentations, primary branding

**Short Logo**: `★ NOVA`
- Use for: Product UI, social media, app icons

**Text-Only**: `NOVA ENTERPRISES`
- Use for: Legal documents, text-only contexts

**Monogram**: `★ N`
- Use for: Favicons, small spaces, app badges

### Logo Usage Rules

**DO:**
- Maintain clear space (minimum 20% of logo width on all sides)
- Use on backgrounds with sufficient contrast
- Scale proportionally
- Use approved color combinations

**DON'T:**
- Stretch, skew, or distort the logo
- Add effects (drop shadows, glows, gradients)
- Place on busy backgrounds without container
- Use unapproved color combinations

## ✍️ Typography

### Font System

#### Primary Typeface: **Inter**
- **Use Cases**: UI, body text, most content
- **Weights**: 
  - Regular (400) — Body text
  - Medium (500) — Subheadings
  - SemiBold (600) — Emphasis
  - Bold (700) — Headings
- **Why**: Modern, highly legible, optimized for screens

#### Display Typeface: **Space Grotesk**
- **Use Cases**: Headlines, hero text, marketing materials
- **Weights**:
  - Medium (500) — Display text
  - Bold (700) — Large headlines
- **Why**: Geometric, futuristic, technical yet approachable

#### Monospace: **JetBrains Mono**
- **Use Cases**: Code, technical data, terminal UI
- **Weight**: Regular (400)
- **Why**: Optimized for code readability, modern aesthetic

### Typography Scale

| Level | Size | Weight | Line Height | Use Case |
|-------|------|--------|-------------|----------|
| **Display** | 72px | Bold 700 | 1.1 | Hero headlines |
| **H1** | 48px | Bold 700 | 1.2 | Page titles |
| **H2** | 36px | SemiBold 600 | 1.3 | Section headers |
| **H3** | 24px | SemiBold 600 | 1.4 | Subsection headers |
| **H4** | 20px | Medium 500 | 1.5 | Card titles |
| **Body Large** | 18px | Regular 400 | 1.6 | Intro paragraphs |
| **Body** | 16px | Regular 400 | 1.6 | Standard body text |
| **Body Small** | 14px | Regular 400 | 1.5 | Secondary text |

## 📸 Photography & Imagery Style

### Visual Style Guidelines

**DO Use:**
- Dark, high-contrast imagery
- Abstract visualizations of data/code
- Modern cityscapes (night shots, neon)
- Futuristic technology close-ups
- Diverse, focused professionals
- Authentic workspace environments

**DON'T Use:**
- Generic stock photos
- Overly staged/cheesy imagery
- Outdated technology (floppy disks, old monitors)
- Clipart or low-quality graphics
- Overly saturated colors

### Image Treatment

**Primary Style**: Dark with color accents
- Base image in grayscale or desaturated
- Overlay with Nova Blue gradient (opacity: 20-30%)
- High contrast, crushed blacks

**Secondary Style**: Minimal & clean
- Lots of negative space
- Single accent color (Nova Blue or Quantum Purple)
- Sharp focus, shallow depth of field

## 🎬 Motion & Animation

### Animation Principles

1. **Purposeful, Not Decorative**
   - Every animation communicates state or draws attention
   - No animation for animation's sake

2. **Fast & Snappy**
   - Durations: 150-300ms (most interactions)
   - Easing: `cubic-bezier(0.4, 0.0, 0.2, 1)` (standard)
   - No slow, drawn-out animations

3. **Consistent Patterns**
   - Same animation for same action across app
   - Predictable behavior builds trust

### Standard Animations

**Button Hover**
```css
transition: all 150ms ease;
transform: translateY(-2px);
box-shadow: 0 8px 16px rgba(0, 102, 255, 0.3);
```

**Card Entrance**
```css
@keyframes slideUp {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
animation: slideUp 300ms ease;
```

**Loading State**
```css
@keyframes pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
animation: pulse 1.5s ease-in-out infinite;
```

**Success Confirmation**
```css
@keyframes checkmark {
  0% {
    stroke-dashoffset: 100;
  }
  100% {
    stroke-dashoffset: 0;
  }
}
```

## 🌐 Digital Presence

### Website Design Patterns

**Homepage Hero**
- Dark background with gradient overlay
- Large, bold headline (Display font, 72px)
- Subheadline explaining value prop
- Primary CTA (Nova Blue, high contrast)
- Animated background (subtle, particles or gradient)

**Product Pages**
- Feature showcase with screenshots/demos
- Alternating left/right layout
- Clear benefits, not just features
- Social proof (metrics, testimonials)
- Strong CTAs throughout

**Documentation**
- Dark mode default
- Syntax highlighting (VS Code Dark+ theme)
- Searchable, well-organized
- Copy-paste friendly code examples
